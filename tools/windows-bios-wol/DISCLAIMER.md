# 使用说明与免责声明

本工具用于在 Windows 中读取和修改与网络唤醒相关的 BIOS 设置。请仅在本人有权管理或已获明确授权的设备上操作，并遵守设备所属组织的管理规定。

可用功能会随主板、固件版本、网络适配器、电源状态和厂商接口而变化。界面推荐值供参考。请在同型号和同固件版本的单台设备上先验证，再用于批量操作。

保存前请记录原始设置并核对实际变更。写入失败、部分成功或回读结果待确认时，请先检查固件当前值。请使用经授权的 BIOS 管理员密码，勿在公开日志、截图或 GitHub Issue 中附带任何凭据。

本工具按现状提供。使用者应对所选配置、操作时机和验证过程负责。适用法律规定的权利与责任仍然有效。
